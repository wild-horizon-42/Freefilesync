## 📘 About

FreeFileSync is a folder comparison and synchronization utility maintained by the FreeFileSync project. It scans two directory trees side by side, highlights new, changed and conflicting files, then lets you mirror, update or two way sync between them. Common uses include keeping a backup drive current, syncing a network share with a local folder, and comparing two versions of a project tree before deciding what to keep. Recent builds add performance tuning for very large folder sets and quieter handling of busy files during batch runs.

If you came looking for a FreeFileSync download for Windows 10 or 11, this page lists the current system requirements, install steps and common troubleshooting fixes.

**Good for:** home users backing up external drives · photographers syncing shoot folders · developers comparing build output · IT staff mirroring network shares · small offices running scheduled backups · anyone reconciling two folder trees

## 🔑 Features

| 🗂️ **Folder comparison** | Side by side view of two folders with clear markers for new, changed and conflicting items |
| 🔁 **Multiple sync modes** | Mirror, update, two way and custom rules so files move in the direction you pick |
| 🛡️ **Backup before delete** | Optional versioning sends replaced or removed files to a timestamped folder |
| ⚙️ **Batch jobs** | Save folder pairs as reusable jobs and chain several of them in one run |
| 🗓️ **Scheduled sync** | Pair with Windows Task Scheduler for automatic recurring sync jobs |
| 🔍 **Filter and exclude** | Include or exclude paths with wildcard rules and size or date filters |
| 📦 **Real time sync** | Watch a folder and trigger the sync when changes are detected |
| 🧾 **Detailed log output** | Per run logs of copied, deleted and skipped files for easy review |
| 💾 **Portable option** | Run from a folder without a full install if you need a moving setup |

## 🛠️ Troubleshooting

| Problem | Solution |
| --- | --- |
| Setup file blocked by SmartScreen | Click **More info**, then **Run anyway** |
| App will not start after install | Confirm you are on Windows 10 or 11 64 bit and reinstall from the same setup file |
| Sync reports busy or locked files | Close the app using the file, then rerun the comparison |
| Very slow scan on large folders | Enable the faster scan option in settings and exclude temporary folders |
| Scheduled task does not run | Check the saved batch job path and confirm the task user has folder access |
| Deleted files are missing after sync | Enable versioning in the sync settings so removed files go to a backup folder |
| Two way sync shows conflicts | Review each conflict entry and pick left or right before running the job |
